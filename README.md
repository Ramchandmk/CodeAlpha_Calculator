# 🧮 Calculator Web Application

A simple and interactive **Calculator Web App** built using **HTML, CSS, and JavaScript** as part of my internship project at CodeAlpha. This project demonstrates core front-end development skills including DOM manipulation, event handling, and responsive layout design.

---

## 🚀 Features

* ➕ Basic arithmetic operations (Addition, Subtraction, Multiplication, Division, Percentage)
* 🧹 Clear (AC) button to reset input
* ⌫ Delete (DEL) button to remove the last character
* 📱 Responsive button grid layout
* ⚠️ Error handling for invalid calculations
* 🎨 Clean and user-friendly interface

---

## 🛠️ Technologies Used

* **HTML5** → Structure of the application
* **CSS3** → Styling and layout (Grid, Shadows, UI design)
* **JavaScript (ES6)** → Logic, DOM manipulation, and event handling
